# Strings
upper()
lower()
rstrip() : Removes tailing characters
replace(): Replaces all occurrence of a string with another string.

Split() : convert the string into  list

centre() : Alliance the string to the centre as per the parameters given by the user.

count() : Returns the number of times the given value has occurred within the given string.

endswith() : Check if the string ends with a given value if yes return True,   or else return False.

find() : Search for the first occurrence of the given value and returns the index where it is present. If not Then it returns -1.

index() : Searches for the first occurrence of the given value returns the index where it is present If absent then raise an exception .

isalnum() : Returns to only if The sting consists of A-Z, a-z, 0-9. If anything other present any other special data present it it returns false.

isalpha() : Returns to only If the entire string only consists A-Z , a-z . Otherwise return false.

istitle() : Returns true only if the first letter of each word of the string is capitalised else it returns false.

title() : Convert the first letter of each word to capital.
